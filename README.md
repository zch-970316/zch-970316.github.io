# zhouchaohui.com

A bilingual, GitHub Pages-ready personal research and notes website.

## Publish on GitHub Pages

1. Create a GitHub repository named `chaohuizhou.github.io` (or another repository if you prefer a project site).
2. Upload the contents of this folder to the repository root and push to the `main` branch.
3. In GitHub: **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. Leave the `CNAME` file in the repository. In the DNS control panel for `zhouchaohui.com`, point the domain to GitHub Pages according to GitHub's custom-domain instructions.
5. When DNS has propagated, enable **Enforce HTTPS** in GitHub Pages settings.

## Customize

Edit `index.html` and replace the visibly marked guidance with your affiliation, research fields, projects, CV link, and external profiles. To add WeChat, replace `wechat-qr-placeholder.svg` with your real QR-code image and update the image name in `index.html`. The website deliberately has no tracking scripts, web fonts, or third-party dependencies.
